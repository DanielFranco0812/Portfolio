# Daniel Franco portfolio

A static portfolio site with no build step. Everything on the page comes from `public/content.json`.

Bit, the pink mascot, wanders the page; click him to say hi.

## Edit

- Change text, projects, the PDC60 course modules and contact links in `public/content.json`.
- Put images in `public/images/` and reference them as `images/your-file.png`.

## Publish

GitHub Pages publishes the `public` folder automatically on every push to `main` (see `.github/workflows/pages.yml`).
